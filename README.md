Marcelo Tours

A simple and responsive website built with HTML5 and CSS3, created to present the Marcelo Tours project — a tourism and guiding service focused on delivering authentic and unforgettable experiences.

✨ Features

📱 Responsive layout that adapts to desktop, tablet, and mobile devices

🎨 Custom CSS styling with a modern and clean design

🧭 Tourism-focused structure, ideal for showcasing destinations and services

⚡ Lightweight and fast loading for smooth navigation

🛠️ Technologies Used

HTML5 — semantic and accessible markup

CSS3 — styling with flexbox/grid and responsive design

🚀 Getting Started


Navigate into the folder:

cd marcelo-tours


Open index.html in your browser:

start index.html   # (Windows)
open index.html    # (Mac)
xdg-open index.html # (Linux)
